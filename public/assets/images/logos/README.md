# Logos des administrations françaises

Ce dossier contient les logos des différentes administrations françaises pour les types d'utilisation dans le formulaire de fréquentation.

## Liste des logos nécessaires

Pour chaque type d'utilisation, veuillez télécharger le logo officiel et le placer dans ce dossier avec le nom suivant :

1. **france-travail.png** - Logo de France Travail (ex-Pôle Emploi)
   - Source : https://www.francetravail.fr

2. **caf.png** - Logo de la CAF (Caisse d'Allocations Familiales)
   - Source : https://www.caf.fr

3. **ameli.png** - Logo d'Ameli (Assurance Maladie)
   - Source : https://www.ameli.fr

4. **logement.png** - Logo pour les demandes de logement social
   - Source : Ministère de la Transition écologique et solidaire

5. **ladom.png** - Logo de LADOM (L'Agence de l'outre-mer pour la mobilité)
   - Source : https://www.ladom.fr

6. **retraite.png** - Logo pour les démarches de retraite (CNAV)
   - Source : https://www.info-retraite.fr

7. **impots.png** - Logo des Impôts (DGFiP)
   - Source : https://www.impots.gouv.fr

8. **ants.png** - Logo de l'ANTS (Agence Nationale des Titres Sécurisés)
   - Source : https://ants.gouv.fr

9. **paiement.png** - Icône pour les paiements de factures

10. **identite.png** - Icône pour les formulaires d'identité

11. **urssaf.png** - Logo de l'URSSAF
    - Source : https://www.urssaf.fr

12. **mdph.png** - Logo MDPH (Maison Départementale des Personnes Handicapées)
    - Source : Votre MDPH locale

13. **banque.png** - Icône pour banque et assurance

14. **education.png** - Logo du Ministère de l'Éducation Nationale
    - Source : https://www.education.gouv.fr

15. **voyage.png** - Icône pour les formalités de voyage

16. **timbres.png** - Icône pour les timbres fiscaux

17. **amendes.png** - Logo pour le paiement des amendes
    - Source : https://www.amendes.gouv.fr

18. **justice.png** - Logo du Ministère de la Justice
    - Source : https://www.justice.gouv.fr

19. **immigration.png** - Logo pour l'immigration
    - Source : https://www.immigration.interieur.gouv.fr

20. **autres.png** - Icône générique pour "Autres"

## Format recommandé

- Format : PNG avec transparence de préférence
- Taille : 48x48 pixels ou 96x96 pixels (sera redimensionné automatiquement)
- Couleurs : Logo officiel en couleur de préférence

## Note

Si un logo n'est pas disponible, l'application utilisera automatiquement une icône emoji comme solution de repli.
